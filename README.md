## 🛠️ Running Locally

### Quick Launch (Double Click)
- Run `Launch-Portfolio.bat` to launch the production build in your browser.
- Run `Dev-Server.bat` to launch the Vite live development server (`http://localhost:3000`).

### Via Terminal
```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev

# 3. Build for production (outputs to /dist)
npm run build

# 4. Preview production build
npm run preview
```

## 🌐 Deploy to Vercel / Netlify / GitHub Pages

The portfolio is pre-configured with relative asset paths (`base: './'`). You can deploy the `/dist` folder directly to any static host:

- **Vercel:** `npx vercel --prod`
- **Netlify:** `npx netlify deploy --prod --dir=dist`
- **GitHub Pages:** Push the repo and point GitHub Pages to `/dist` or the root branch.
